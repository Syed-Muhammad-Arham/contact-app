# 📱 Next-Level Contact App (Glassmorphism UI)

A sleek, modern, and highly responsive contact management application built with React and Vite. It features a premium "Glassmorphism" UI with an animated gradient background, proving that you don't always need heavy UI libraries to create stunning web interfaces.

## ✨ Features

- **Add Contacts:** Easily save names and phone numbers.
- **Real-time Search:** Filter through your contacts instantly without refreshing.
- **Glassmorphism Design:** Frosted glass effect with blur and transparency.
- **Animated Gradient Background:** Smooth, continuous background color transitions.
- **Micro-interactions:** Smooth hover effects and list animations.

## 🛠️ Tech Stack

- **Frontend:** React.js (Hooks: `useState`)
- **Build Tool:** Vite (Super fast HMR)
- **Styling:** Pure CSS3 (No external CSS frameworks)

## 🚀 How to Run Locally

1. Clone the repository:
   git clone https://github.com/Syed-Muhammad-Arham/contact-app.git
2. Navigate to the project directory:
   cd contact-app
3. Install dependencies:
   npm install
4. Start the development server:
   npm run dev
